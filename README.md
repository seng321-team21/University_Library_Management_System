# University Library Management System
Web-based University Library Management System and OpenAPI contract for SENG 321.

## Running the Backend (Sprint 2)

Requires Node.js 20+. No dependencies to install.

```bash
cd backend
npm test     # run tests
npm start    # API on http://localhost:8080/api/v1
```
